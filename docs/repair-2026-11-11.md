# Restore CLI build and quality gate — 11 November 2026

## PRD
Make the shipped CLI compile from its actual source and test the installed entry point.

## SRS
Preserve the command interface and cli/dist output. Quality checks must fail on
failed or missing tests and must not use a Python unittest runner for JS tests.

## Design / ADR
Source lives in src, not cli/src. Keep cli/dist for compatibility with start/bin.
Use the existing Vitest dependency and exercise the compiled CLI help/version in
subprocesses, without installing skills or making network requests.

## Plan
Reproduce TS18003 and zero unittest discovery, fix source paths, replace the vacuous
smoke test with packaging checks, and run npm build/test and doctor.

## Given / When / Then
Given a clean build, when the package's CLI is invoked with --version or --help,
then it exits successfully and describes the supported interface.

## Remaining scope
Registry catalog availability, remote installation safety and the referenced
validate-registry/generate-index scripts remain separate unresolved checks.
